A small release that puts the settings of an upload where you start it. The build
description, the branch to set live and the two upload options have moved from the
Project tab to the Upload tab, next to *Upload build*.

## Changed

### Upload settings are on the Upload tab

- **Build description**, **Set live on branch**, **Preview build** and **Verbose steamcmd
  output** now sit in a card at the top of the Upload tab, just above *Preview contents* and
  *Upload build*. They describe one upload, not the project, so you can now check them, and
  change the description, right before pressing the button.
- The **Project tab** is left with what configures the project: name, App ID, the app/game
  build and upload logs/VDF folders, the Steam account and password, and the project's
  Web API key.
- These are still saved with the project, as before. Uploads, exported `.vdf` scripts and
  the exported GitHub Actions workflow use them exactly as in 1.4.0, so there is nothing to
  redo in your projects.

### The build description

- The field stops at **250 characters**. That is the length the build script has always
  kept; before, longer text was cut silently when uploading.
- Its tooltip now says two more things. Players never see the description: it appears only
  in the Steamworks admin panel and on the Builds tab. And it is saved with the project, so
  change it before each upload, or every build gets the same text.

## Upgrading from 1.4.0 or 1.3.0

- Installed and portable copies of 1.3.0 and 1.4.0 offer this version in the status bar and
  in Settings, under *Updates*. Your projects, saved passwords and API keys carry over
  unchanged.
- Coming from 1.3.0, read the
  [1.4.0 notes](https://github.com/Andrea332/SteamPipe-Studio/releases/tag/v1.4.0) too:
  they cover the per-project Web API key, the password check, the tooltips and Settings
  moving to the bottom of the project list.
- Coming from 1.2.0 or earlier? Those versions have no updater, so install this one by
  hand once from the files below.

## Known issues

- **A project's own Web API key has still not been tried against Steam with keys from two
  different partners.** If a project's own key is not picked up, please open an issue.
- **The packages are not code-signed yet.** The first time, Windows SmartScreen shows
  "Windows protected your PC": choose *More info → Run anyway*. macOS refuses software from
  an unidentified developer: Control-click the package or the app and choose *Open*, or
  allow it under *System Settings → Privacy & Security*.
- **The macOS packages have not been tried on a real Mac yet.** If something does not work
  there, please open an issue with your macOS version and chip.
- **A portable copy's first update downloads the full package** (about 50 MB), because the
  portable archive does not include the package that updates are calculated from. Later
  updates, and every update of an installed copy, download only the differences.
